# smena

Prebuilt releases of **smena**, a task management CLI that keeps AI agent context durable across sessions.

## Install

```bash
brew install antonlisovoy/tap/smena
```

Or download an archive for macOS / Linux (arm64, amd64) from [Releases](https://github.com/AntonLisovoy/smena-cli/releases).

This repository contains release artifacts only.
